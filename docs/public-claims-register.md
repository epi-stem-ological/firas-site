# Public Claims Register

This register tracks public-facing claims that appear on, recently appeared on, or are planned for firasfreajah.com. It is intentionally public-safe. Do not add source documents, private financial backup, internal project names, client details, architecture details, screenshots, contracts, internal records, vendor incidents, or sensitive explanations.

Validation status values:

- Published, needs validation: already public or recently public, but evidence and public-safety status should be confirmed before expansion.
- Softened in current branch: no longer presented as a hard public metric or credential in live UI copy.
- Validate before expanding: safe at a general level, but needs confirmation before stronger language, case studies, or metrics.
- Remove unless verified: should stay out of public copy unless Firas confirms it is current, accurate, and public-safe.
